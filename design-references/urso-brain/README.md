# Urso Brain — design references

Primary direction: **Sana’s calm enterprise workspace**, adapted to Urso’s governed knowledge model.

Page decisions:

- Shell — fixed 280px pale sidebar, pill navigation, wide white work surface, generous gutters, and no tabs or file tree.
- Home — Sana-style two-column workspace overview with project rows, department scope, current knowledge, and conversations.
- Ask Brain — one focused conversation surface; conversation history opens on demand instead of becoming a second permanent sidebar.
- Projects and departments — Sana “Browse agents” directory pattern with two-column entries and expandable source detail.
- Knowledge — Sana “Search” pattern with a large pill search field, source filters, and quiet result rows.
- Graph — the deliberate exception: the vault explorer opens beside a deterministic cluster map. Company core, rules, projects, and departments occupy stable labeled regions; cross-group links stay quiet until selected or explicitly revealed; a node inspector explains ownership, provenance, and direct relationships.
- Settings — Sana modal/panel pattern with large rounded sections and clear ownership boundaries.
